# Advanced Animated Responsive Calculator

This project now includes:

- A responsive, animated calculator UI
- Advanced operations:
  - `+`, `-`, `*`, `/`, `%`, `^`
  - Parentheses
  - `sin`, `cos`, `tan`
  - `sqrt`, `log`, `ln`, `abs`
  - Constants `π` and `e`
- Keyboard support for common calculator input
- A small chat section to answer user queries and evaluate expressions

## Run

Open `hello.html` in a browser.
